# VibeShop Wiki

**VibeShop** è una piattaforma web per la gestione di concerti, artisti, merchandising, carrello, ordini e pannello amministratore.

Il progetto è stato sviluppato come applicazione Java Web basata su **JSP, Servlet, DAO e MySQL**. L'obiettivo è offrire una base completa per un sito dedicato al mondo musicale: eventi live, artisti, prodotti e gestione degli ordini.

## Obiettivo

VibeShop permette agli utenti di:

- consultare i concerti disponibili;
- scoprire artisti;
- visualizzare prodotti di merchandising;
- aggiungere prodotti e biglietti al carrello;
- completare un ordine;
- consultare la cronologia degli ordini.

L'amministratore può invece gestire i principali contenuti del sito tramite un pannello dedicato.

## Tecnologie

- JSP
- Servlet

- MySQL
- HTML

## Stato del progetto

Il progetto è nato in ambito universitario, ma può essere esteso come base commerciale per agenzie musicali, organizzatori di eventi, artisti o piccoli brand legati alla musica live.

Le evoluzioni future possono includere:

- upload immagini dal pannello amministratore;
- pagamenti reali tramite provider esterni;
- email automatiche di conferma ordine;
- gestione completa degli artisti;
- deploy professionale su server;
- miglioramenti di sicurezza e scalabilità.
