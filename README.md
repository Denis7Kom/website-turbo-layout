# Turbo Layout

Turbo Layout is a team website project created as part of our web development work.

## Project goal

The goal of this project is to build a clean, responsive website with a registration page and a consistent visual style.

## Technologies

- HTML
- CSS
- JavaScript
- JSP
- Servlet
- Git / GitHub

## Team workflow

We use GitHub for collaboration:

1. Create a separate branch for each task.
2. Make changes only in your own branch.
3. Open a Pull Request into `main`.
4. Wait for review before merging.
5. Keep commits clear and meaningful.
