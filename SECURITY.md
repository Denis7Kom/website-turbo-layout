# Security Policy

## Supported versions

The current active version of VibeShop is the only supported version.

| Version | Supported |
| ------- | --------- |
| main    | Yes       |
| older branches | No |

## Reporting a vulnerability

If you find a security issue, do not open a public GitHub issue.

Instead, contact the maintainers privately.

Please include:

- affected page or feature;
- steps to reproduce;
- expected impact;
- screenshots or logs if available;
- suggested fix, if known.

## Security scope

Security-sensitive areas include:

- authentication;
- registration;
- user profile;
- shopping cart;
- order flow;
- payment integration;
- admin functionality;
- API endpoints;
- database-related logic.

## Do not report

Do not report issues based only on:

- theoretical vulnerabilities without reproduction steps;
- automated scanner output without validation;
- attacks requiring full access to a developer machine;
- issues already fixed in the latest branch.

## Sensitive data

Never commit or publish:

- passwords;
- API keys;
- payment provider credentials;
- database dumps;
- private user data.
