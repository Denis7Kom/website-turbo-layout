# Code of Conduct

## Our standards

All contributors to VibeShop are expected to communicate respectfully and professionally.

Acceptable behavior:

- constructive feedback;
- clear technical discussion;
- respectful disagreement;
- focus on code, architecture, design, and project quality.

Unacceptable behavior:

- personal insults;
- harassment;
- offensive comments;
- spam;
- intentionally disruptive behavior;
- publishing private information.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict participation if behavior damages the project or the team workflow.

## Scope

This code of conduct applies to:

- issues;
- pull requests;
- code reviews;
- project discussions;
- repository-related communication.
